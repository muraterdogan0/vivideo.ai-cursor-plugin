# Vivideo — AI Video Generator for Cursor

Create and manage AI videos with [Vivideo](https://vivideo.ai) directly from
Cursor. Turn prompts or images into videos, use avatars and brand kits, and check
render status without leaving your development workflow.

This plugin connects Cursor to the Vivideo MCP server. Videos are generated by
Vivideo — Cursor does not render video itself.

## What you can do

- Generate a video from a text description
- Get a video plan (title, script, style and scenes) written by Vivideo, ask for a
  change, then make the video
- Turn an image into video (image-to-video)
- Use Vivideo avatars, voices, and brand kits
- Estimate credit cost before generating
- List your videos and check render status

## Requirements

- A [Vivideo](https://vivideo.ai) account. You will be asked to sign in and
  authorize Cursor the first time you use the plugin.
- On a free Vivideo account, Vivideo writes a video plan for your request that you
  can review and change once. The finished video is made after you start a
  Vivideo plan on vivideo.ai; the plugin gives you the link.
- On a paid account, rendering consumes Vivideo credits. Listing videos and
  checking status do not consume credits.

## Installation

### From the Cursor Marketplace

Search for "Vivideo" in the Cursor Marketplace and install it.

### Local development

```bash
git clone <this-repository> ~/.cursor/plugins/local/vivideo
```

Then run **Developer: Reload Window** in Cursor.

## Authorization

On first use, Cursor opens the Vivideo authorization page. Sign in and grant
access, and Cursor reconnects automatically. The plugin ships **no secrets** —
authorization uses OAuth 2.0 with PKCE, and no client secret, API key, or access
token is stored in this repository.

The plugin requests these scopes:

| Scope | Purpose |
| --- | --- |
| `openid`, `email` | Identify your Vivideo account on first connection |
| `vivideo:account:read` | Read your plan and credit balance |
| `vivideo:videos:read` | List your videos and check render status |
| `vivideo:videos:create` | Create new videos |

## Example requests

```text
Create a 10-second 9:16 product launch video for this mobile app.

Turn this product image URL into a cinematic image-to-video clip.

Create an avatar video announcing the feature described in this README.

Show my latest Vivideo video and tell me whether it is ready.
```

Two commands are also included:

- `/vivideo-create` — create a video from a description
- `/vivideo-status` — check the status of your videos

## Data handling

Your prompts and any image URLs you provide are sent to the Vivideo API to
generate videos, and your generated videos are stored in your Vivideo account.
The plugin reads your source code only when you explicitly ask it to use that
content in a video.

Vivideo processes submitted prompts, image URLs and generated video data as
described in the Vivideo Privacy Policy. The plugin does not store OAuth client
secrets, API keys or access tokens in its public repository.

- Privacy policy: https://vivideo.ai/privacy-policy
- Terms: https://vivideo.ai/terms-of-service
- Support: support@vivideo.ai

## Limitations

- Rendering requires Vivideo credits on a paid plan; free accounts get a video
  plan and finish the video on vivideo.ai.
- Video generation is asynchronous. A newly created video is usually queued or
  processing, not immediately ready.
- Rich video preview cards are not rendered inside Cursor; the plugin reports
  status and links instead.
